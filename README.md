# Interface

A multi-page React web app with Bootstrap 5 styling, Framer Motion animations,
and React Router navigation.

## Components

```
src/components/
  Navbar.js      # Top navigation bar
  Header.js      # Hero/header section
  MainBody.jsx   # Main content area
  AboutUs.jsx    # About page
  Footer.js      # Footer
```

Each component has a matching `.css` file for custom styles on top of Bootstrap.

## Dependencies

React, React Router, Bootstrap 5, Framer Motion, Lucide React, React Icons,
React Typing Effect, Font Awesome

## Run

```bash
npm install
npm start
```

Opens on [http://localhost:3000](http://localhost:3000).
